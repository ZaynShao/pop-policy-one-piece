## 4. visit marker 算法当前参数表(2026-05-19 v2)

权威实现:`apps/web/src/lib/visitMarker.ts`。

### 4.1 同坐标蜂窝聚合(`layoutCluster`)

| 参数 | 值 | 含义 |
|---|---|---|
| `PADDING_FACTOR` | **0.9** | 圆心距 = size × 0.9 → 两两重叠面积 ≈ 45% πr² |
| `baseSize`(全国) | 8px | n=1 时的圆直径 |
| `baseSize`(省下钻) | 14px | 同上 |
| `minSize`(全国/省) | 3px / 4px | 兜底最小直径,触底后接受溢出 |
| `maxClusterRadius`(全国/省) | 24px / 36px | 整组半径上限,超出则等比缩小 size |
| 几何形态 | 六边形堆积 | 第 0 层 1 + 第 k 层 6k 个,中心 (0,0) 起 |
| 中心放谁 | daysAgo 最小(最新)| `sorted = indices.sort((a,b)=>da-db)` |
| 渲染顺序 | 距中心远→近 | 中心点最后画(echarts 同 series 后画的在上),防止外环边缘盖中心 |
| 落地实现 | echarts data-item 级 `symbolOffset` | 像素级,zoom 改变时不需重算 |

### 4.2 时间 lightness 衰减(`decayLightnessByAge`)

| daysAgo 区间 | factor | 备注 |
|---|---|---|
| 0-14d | 1.0 | 原色 |
| 14d → 60d | 1.0 线性插值到 0.45 | 14-60d 段斜率 -0.012/d |
| 60d → 120d | 0.45 线性插值到 0.22 | 60-120d 段斜率 -0.0038/d |
| 120d+ | 0.22 | 触底 |
| `MIN_LIGHTNESS` | 12 | HSL L 下限,防变全黑 |
| cancelled | 跳过衰减 | 颜色是 rgba 灰,非 hex 直接 return |
| planned 未来日期 | daysAgo<0 按 0 处理 | 保持原色 |

### 4.3 v2 调参历史(给以后想再调参的人参考)

- v1(PR #29):PADDING 1.18(30% overlap),衰减 ×0.6/×0.4,MIN_L 20

### 7.2 新增 — visit 增删 via API

```bash
# 登录拿 token
TOKEN=$(curl -sS -X POST https://xiaojuenergy.com/api/v1/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"sysadmin","password":"pop2026"}' \
  | python3 -c "import sys,json; print(json.load(sys.stdin)['accessToken'])")

# 建 visit(后端按 provinceCode + cityName 自动 city center lookup)
curl -sS -X POST https://xiaojuenergy.com/api/v1/visits \
  -H 'Content-Type: application/json' \
  -H "Authorization: Bearer $TOKEN" \
  -d '{
    "status": "completed",
    "visitDate": "2026-05-19",
    "department": "...",
    "outcomeSummary": "...",
    "color": "green",
    "provinceCode": "440000",
    "cityName": "清远市"
  }'

# 删 visit(soft delete,进回收站)
curl -X DELETE -H "Authorization: Bearer $TOKEN" \
  https://xiaojuenergy.com/api/v1/visits/<UUID>
```
